## 2. Information-Theoretic Observation Geometry v0.2

### 2.1. Закрытые дефекты v0.1

| Дефект v0.1 | Исправление v0.2 |
|---|---|
| Неявное соглашение о натуральном логарифме | Все величины параметризованы основанием \(b>1\): \(H_b\), \(I_b\), \(D_{\mathrm{KL},b}\) |
| Энтропия трактовалась без полного паспорта единицы | Доказана теорема смены информационной единицы \(H_b=\log_b(c)H_c\) |
| «Дефект канала» не отделялся от априорного распределения | Сырой дефект определён как \(\mathscr D^{\mathrm{info}}_{\lambda,b}(P_X)=H_b(X\mid Y_\lambda)\), явно зависящий от \((P_X,W_\lambda)\) |
| Нормировка могла делить на ноль | Введена base-invariant нормировка и политика вырожденного источника \(H_b(X)=0\mapsto\delta=0\) |
| Детерминированная карта и шумовой канал смешивались | Зафиксирована цепочка \(R_\lambda\to O_\lambda\to K_\lambda\to\widehat q_\lambda\) |
| Хроматический пример допускал ложный ненулевой дефект для \(C=c(P)\) | Доказано: для детерминированного поля \(H_b(C\mid P)=0\); ненулевой дефект требует условной множественности меток |
| Непрерывная энтропия содержала логарифм размерной плотности | Введён опорный объём \(v_*\): \(h_{b,v_*}=-\int p_X\log_b(p_Xv_*)\,dx\); unreferenced shorthand запрещён |
| Recoverability не имела приближённого барьера | Добавлена строгая формулировка неравенства Фано с односторонней интерпретацией |
| Information bottleneck был записан без всех условий | Явно указаны \(Q-X-Y\), класс каналов, бюджет и условия существования |
| Физическая distortion могла входить в безразмерную задачу напрямую | Введено \(d_Q/d_{\mathrm{ref}}\) с совпадающей размерностью и положительной опорой |

### 2.2. Статус утверждений

Строгими стандартными результатами являются:

- смена основания логарифма;
- энтропийное разложение;
- формула по волокнам детерминированного наблюдения;
- data-processing inequality и монотонность дефекта;
- KL contraction;
- критерий точной восстановимости \(H_b(Q\mid Y)=0\);

Information bottleneck и rate-distortion записаны как `model`, а не как новые теоремы.

## 3. Metric Entropy and Observational Entropy Defect v0.2

### 3.1. Закрытые дефекты v0.1

| Дефект v0.1 | Исправление v0.2 |
|---|---|
| \(\log(1/\varepsilon)\) при размерном \(\varepsilon\) | Используется \(\log_b(\ell_*/\varepsilon)\) либо \(\rho=\varepsilon/\ell_*\) |
| Один символ \(\varepsilon\) перегружал входное и выходное пространства | Введены \(\varepsilon_X\) и \(\varepsilon_Y\) |
| Lipschitz bound скрывал тип \(L_O\) | \(L_O\) имеет тип \(U_Y/U_X\), а масштабы согласованы условием \(L_O\varepsilon_X\le\varepsilon_Y\) |
| Неотрицательность дефекта зависела от условного \(\varepsilon/L\) | Введён matched-scale defect с прямой теоремой неотрицательности |
| Не было закона композиции | Доказано точное телескопирование дефектов при двух согласованных масштабных условиях |
| Смена единиц длины не была теоремой | Доказано \(N_{a\varepsilon}(A,ad)=N_\varepsilon(A,d)\) |
| Box dimension использовала размерный логарифм | Нижняя и верхняя box-dimension определены через фиксированную \(\ell_*>0\); доказана независимость от базы и единицы |
| Heat parameter ошибочно интерпретировался как время | Геометрический параметр \(s\) имеет размерность \(L^2\); физическое время входит только через \(s=\kappa t_{\mathrm{phys}}\) |
| \(\log Z_g\) назывался энтропией без состояния | Он переименован в heat-trace complexity и отделён от Shannon/von Neumann/thermodynamic entropy |
| Curvature, gradient и entropy-pressure складывались без единиц | Все компоненты сначала нормируются; разрешена только dimensionless decision scalarization |
| Chromatic metric не имела паспорта \(\lambda\) | \(\lambda\) имеет тип \([d_X]/[d_C]\), а \(\lambda L_c\) безразмерно |
| Shell graph смешивал радиус и tolerance без контроля | \(d\), \(r\), \(\sigma\) имеют один тип; доказана ковариантность при согласованном масштабировании |

### 3.2. Новые строгие интерфейсные результаты

- matched-scale covering contraction;

Эти результаты в основном являются стандартными следствиями метрической, римановой и спектральной геометрии. Композиционный закон — полезная интерфейсная лемма, но его самостоятельная научная новизна не установлена.

## 4. Машинная проверка

Reference-ledgers проверяют:

- сигнатуры reduction/observation/channel/estimator;
- семикомпонентные физические размерности;
- семантические типы `probability`, `information`, `loss`, `count`, `scalar`;
- обязательное основание каждого информационного логарифма;
- безразмерность аргументов логарифмов и экспонент;
- положительные reference/zero policies;
- согласованность heat scale, curvature scale и chromatic converter;
- полный набор полей GO observation protocol;
- непустые гипотезы всех сильных утверждений.

Регрессионные тесты отдельно проверяют:

- Shannon decomposition и parity aliasing;
- base invariance нормированных информационных и метрических дефектов;
- data processing и KL contraction;
- binary symmetric channel и Fano equality в бинарном случае;
- covering-packing sandwich;
- coherent metric rescaling;
- matched Lipschitz contraction;
- точное телескопирование дефектов;
- product covering bounds;
- circle/parity resolution thresholds;
- chromatic graph sandwich;
- geometric heat exponent и diffusion conversion.

## 5. Строгая публикационная оценка

Оба документа теперь математически пригодны как:

- нормативные главы общего GO Core;
- технические приложения к более сильной основной статье;
- самостоятельные expository/framework notes с честно ограниченным claim scope.

Они пока **не являются самостоятельными новыми исследовательскими статьями высокого уровня**, поскольку основные теоремы стандартны, а оригинальность интерфейсной сборки не заменяет новый математический результат. Для самостоятельной публикации требуется один из следующих слоёв:

1. новый sharp bound для совместной информационно-метрической восстановимости;
2. теорема эквивалентности/разрыва между probabilistic и covering defects при проверяемых классах источников;
3. оптимальный auxiliary-channel design с доказанной нижней/верхней границей;
4. minimax/sample-complexity theorem, зависящая от quotient/fiber metric entropy;
5. нетривиальный композиционный bound при шуме, случайных масштабах и несовпадающих протоколах.

## 6. Оставшиеся ограничения

- Основной Shannon-слой доказан для конечных алфавитов; standard-Borel extension дана только через relative entropy и quantizers.
- Не построена полная rate-distortion theory для GO-протоколов.
- Covering results требуют непустых totally bounded/compact sets в соответствующих местах.
- Heat-trace theorem ограничен замкнутыми многообразиями без края.
- Reference-ledger проверяет типы и контракт, но не является формальным доказательным ассистентом.
- Полный corpus strict-run по-прежнему обязан завершаться кодом 1, пока 13 оставшихся модулей не мигрированы.
